# RNA-seq-analysis
Scripts used to analyze RNA-seq data from Mycobacterium tuberculosis

RNAseq_DESeq2_pipeline_v3.3.2.R
The DESeq2 R script used to analyze RNA-seq data

Volcano_plot_generic_1.2.17.R
Generic volcano plot script crafted in R to visualize and customize volcano plots from Tn-seq and RNA-seq data. 

flavoprotein_enrichment_v1.R
R script used to identify flavoprotein differentially expressed genes using H37Rv DESeq2 data and a manually curated file containing the all flavoproteins for H37Rv identified by UniProt.
